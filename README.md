## Important
The included images are clearly labeled product placeholders so the website works immediately. Replace each SVG in `images/` with the exact product photograph you want to display, keeping the same filename (or update the image path in `index.html`).

## GitHub Pages
Upload `index.html`, `style.css`, and the `images` folder to your GitHub repository, then enable GitHub Pages under Settings → Pages → Deploy from branch → main → / (root).
